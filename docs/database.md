# Database

Import `schoolmanagement.sql` into a database called `schoolmanagement`.

| Table | Holds |
| --- | --- |
| `tbl_login` | Admin accounts (`loginid`, `password`) |
| `tbl_course` | Courses with short and full names and dates |
| `subject` | Three subjects for each course |
| `registration` | One row per registered student |
| `session` | Academic sessions and which one is active |
| `countries`, `states`, `cities` | Location lists for the registration form |
